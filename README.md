# مغامرات لولو · Lulu's English Adventure

لعبة تعليمية ثلاثية الأبعاد للأطفال (4 إلى 6 سنوات) لتعلّم الإنجليزية باللعب، مع دعم العربية.
**العب، اكتشف، وتكلّم بالإنجليزية! · Play, Discover & Speak English!**

## التشغيل
- افتح رابط GitHub Pages للمستودع، ثم من المتصفح اختر «إضافة إلى الشاشة الرئيسية» لتثبيتها كتطبيق.
- بعد أول فتح، تشتغل اللعبة بدون إنترنت (Service Worker يحفظ كل الملفات).

## ما في النموذج الأولي
- 4 شخصيات أصلية ثلاثية الأبعاد: لولو، بيبو، بندق، توتة (حركة، رمش، تعابير، تحريك الفم مع الصوت).
- خريطة 6 عوالم، والعالم الأول «جزيرة الفواكه» كامل بخمس مراحل: تعرّف، اسمع واختر، اجمع وعُد، طابق الكلمة، انطق الكلمة.
- نجوم، صناديق مفاجآت، ملابس وإكسسوارات، حقيبة الكلمات، أوسمة وشهادة إنجاز.
- لوحة ولي الأمر (محمية بسؤال حسابي): الكلمات المتعلّمة والتي تحتاج مراجعة، مستوى الاستماع والنطق، وقت اللعب اليومي وتقرير الأسبوع، الإعدادات وحد اللعب اليومي.
- الخصوصية: لا إعلانات، لا مشتريات، لا محادثات، وكل البيانات محفوظة على الجهاز فقط.

## التطوير
```
npm install
npm run build      # يبني docs/ (التطبيق المنشور)
```
- `src/data.js`: العوالم والكلمات والمراحل (أضف عالماً جديداً هنا).
- `src/lines.json`: كل جمل الشخصيات (عربي وإنجليزي).
- `src/characters.js`, `src/props.js`, `src/worlds.js`: المجسمات ثلاثية الأبعاد (three.js) بدون ملفات خارجية.
- `tools/`: سكربتات توليد الأصوات (Kokoro للإنجليزي، Chatterbox للعربي) وفحص النطق بـ Whisper.
- `audio/`: ملفات الصوت المولّدة.
